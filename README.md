# MIDI FIELD PLAYER for OP-1 Field

An open-field Level 5 sequencer pack that plays Standard MIDI Files from the `midiplayer` folder on the OP-1 Field.

## Release 1.3 (pack version 14)

- Plays SMF format 0 and 1 MIDI files with tempo events and multiple tracks.
- Graphical scrolling piano roll and keyboard.
- Song-name marquee for long filenames, transport status icon and elapsed/total time.
- Play/pause, once/loop, speed and live pitch transpose.
- Contextual HELP screen (hold HELP while on the sequencer page).
- Notes are played through the open-field sequencer note interface; MIDI output depends on the OP-1 Field's MIDI configuration.

## Installation

Requires OP-1 Field OS **1.7.3** with compatible open-field base support (level 5).
Copy `midiplayer.pack` to the OP-1 Field's **MTP `packs`** folder, then restart/reload as required by open-field. Do not confuse the MTP folder with the ordinary USB disk mode. Put `.mid` files in the open-field-created MTP `midiplayer` folder. Do not keep multiple installed packs with the same `midiplayer` identifier.

## Controls

| Control | Action |
|---|---|
| Blue encoder turn | Choose MIDI file |
| Blue encoder press | Play / Pause |
| Orange encoder turn | Left = ONCE, right = LOOP |
| White encoder turn | Speed |
| White encoder press | Stop / rewind |
| Red encoder turn | Pitch transposition while playing |
| HELP held | Display contextual controls |

## Build from source

The included `midiplayer/recipe.json` is intended for the [open-field](https://github.com/LaP0573/open-field) build system. Place the `midiplayer` directory in the root of a compatible open-field checkout, then:

```powershell
python -I tools/pack_build.py card --recipe midiplayer/recipe.json --out midiplayer/midiplayer_card.s
python -I tools/pack_build.py build3 --recipe midiplayer/recipe.json --profile profiles/op1f-1.7.3.json --out midiplayer.pack
python -I tools/pack_build.py check --pack midiplayer.pack
```

The card source `midiplayer_card.s` is generated by the first command and is **not** part of this source archive. The published pack is the exact supplied 1.3 Scrollfix binary, not a newly rebuilt binary.

## Current limits

- Maximum MIDI file data: 65,536 bytes; maximum parsed events: 6,144; maximum tracks: 32.
- Playback uses the open-field note interface; it does not provide independent per-channel MIDI output routing.
- Overlapping repeated note-ons on the same channel and pitch may be imperfectly represented in edge cases.
- Hardware verification of this exact 1.3 Scrollfix binary should be documented before submitting to the official catalog. Build and structural pack checks alone cannot confirm runtime behavior.
